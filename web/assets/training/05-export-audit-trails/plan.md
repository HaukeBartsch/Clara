# Export audit trails

Every change to a project's design and data, and every export, is written to the audit log. Administrators read and export it in the Control Panel.

1. Choose **Control Panel** in the header and **Audits** in the left panel. Narrow the list with the filters: the log (events or views), the project, the user, the event type and a date range. Choose **Filter** to apply them.
2. Choose **Export CSV**. The download is a ZIP file with one CSV of every entry that matches the filters, not only the entries on the screen. When the export would be very large (more than 1 GiB), you are asked to confirm first.

## Good to know

The audit log cannot be changed or deleted from the user interface.
