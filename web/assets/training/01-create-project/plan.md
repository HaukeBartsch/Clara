# Create a new project

An administrator creates the project in the Control Panel and adds the people who will work in it.

Each step below matches one picture.

1. On the start page, choose **Control Panel** in the header. Only administrators see this button.
2. In the left panel choose **Projects**, then **New project**. Fill in the project name, the main supporting institution, and the principal investigator, and choose **Create project**. The participant name pattern is derived from the project name (for example `HEART_STUDY_[0-9][0-9][0-9]`). Fields marked with * are required; the REK number and the dates can be added later with **Edit**.
3. The project starts with one arm, a **baseline** event and an empty first instrument. Choose **Open …** to go into the new project.
4. In the project's left panel choose **Members**. Pick an account and a role and choose **Add member**. A member without a role has full permissions. The member's project token is shown once, right after adding.
