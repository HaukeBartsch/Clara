# Eksportere data

Last ned prosjektets data som CSV eller JSON, prosjektet som en CDISC ODM-XML-fil, eller datadictionaryen som en REDCap-instrument-ZIP. Hva datafilen inneholder, følger eksportrettighetene dine.

1. Åpne prosjektet og velg **Eksport** i panelet til venstre.
2. Velg format, om valg skrives som koder eller etiketter, kolonneoverskriftene og, for CSV, skilletegn og desimalseparator. **Anvendt følsomhet** viser nivået filen blir eksportert på. Velg **Last ned data**.
3. **Eksporter prosjektet som CDISC ODM** skriver prosjektet i én XML-fil som et annet fagsystem kan lese. Velg **ODM-versjon**, og under **Innhold** enten **Prosjekt og data** eller **Bare prosjektet** — strukturen uten registrerte feltverdier. Bare administratorer ser denne delen.
4. **Last ned datadictionary** gir prosjektets utforming uten registrerte feltverdier. Siden **Utforming** i et annet prosjekt kan importere den.

## Verdt å vite

- Hver nedlasting blir ført i revisjonsloggen med nivået som ble brukt.
- Slå på **Merk filen som UTF-8 for Excel** når filen skal åpnes direkte i Excel, slik at æ, ø og å vises riktig.
