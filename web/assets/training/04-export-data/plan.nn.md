# Eksportere data

Last ned dataa til prosjektet som CSV eller JSON, prosjektet som ei CDISC ODM-XML-fil, eller datadictionaryen som ei REDCap-instrument-ZIP. Kva datafila inneheld, følgjer eksportrettigheitene dine.

1. Opne prosjektet og vel **Eksport** i panelet til venstre.
2. Vel format, om val blir skrivne som kodar eller etikettar, kolonneoverskriftene og, for CSV, skiljeteikn og desimalskiljeteikn. **Anvendt følsemd** viser nivået fila blir eksportert på. Vel **Last ned data**.
3. **Eksporter prosjektet som CDISC ODM** skriv prosjektet i éi XML-fil som eit anna fagsystem kan lese. Vel **ODM-versjon**, og under **Innhald** anten **Prosjekt og data** eller **Berre prosjektet** — strukturen utan registrerte feltverdiar. Berre administratorar ser denne delen.
4. **Last ned datadictionary** gir utforminga til prosjektet utan registrerte feltverdiar. Sida **Utforming** i eit anna prosjekt kan importere ho.

## Verdt å vite

- Kvar nedlasting blir ført i revisjonsloggen med nivået som vart brukt.
- Slå på **Merk fila som UTF-8 for Excel** når fila skal opnast direkte i Excel, slik at æ, ø og å blir viste riktig.
