# Eksportere data

Last ned dataa til prosjektet som CSV eller JSON, struktur og data som ei CDISC ODM-XML-fil, eller datadictionaryen som ei REDCap-instrument-ZIP. Kva datafila inneheld, følgjer eksportrettigheitene dine.

1. Opne prosjektet og vel **Eksport** i panelet til venstre.
2. Vel format, om val blir skrivne som kodar eller etikettar, kolonneoverskriftene og, for CSV, skiljetegn og desimalskiljeteikn. **Anvendt følsemd** viser nivået fila blir eksportert på. Vel **Last ned data**.
3. **Export project as CDISC ODM** skriv strukturen til prosjektet og dataa i éi XML-fil, i den ODM-versjonen du vel, til eit anna fagsystem. Denne biten ser du som prosjektadministrator.
4. **Last ned datadictionary** gir utforminga til prosjektet utan registrerte feltverdiar. Sida **Utforming** i eit anna prosjekt kan importere ho.

## Verdt å vite

- Kvar nedlasting blir ført i revisjonsloggen med nivået som vart brukt.
- Slå på **Merk fila som UTF-8 for Excel** når fila skal opnast direkte i Excel, slik at æ, ø og å blir viste riktig.
